COMMUNICATION SUMMARY
=====================

Browser  <---- HTTPS / JSON ---->  Express REST API

Express API  <---- internal calls ---->  Algorithm Engine

Express API  <---- database queries -->  Neon PostgreSQL

Browser  <---- map tile requests ----->  OpenStreetMap

Frontend is public-facing.
Database credentials remain exclusively on the backend.
